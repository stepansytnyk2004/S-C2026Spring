# S-C2026Spring
Sensors and Control Spring 2026 Project Assignment -> **Chosen Track: Track B**
#
We have implemented a UR3 within MuJoCO that picks up a Candy Jar and places it into a basket. Through a wrist-mounted RGB-D camera, it is able to detect and move to the Candy Jar using IBVS or PBSV. To prove functionality, the Candy Jar's location is randomized throughout each trial.
